# A simple features object of the world land map

An integrated land map

## Usage

``` r
WorldLandMap
```

## Format

A simple features object

- featurecla:

  Land area

- geometry:

  Geometry unit

## Source

`rnaturalearth::ne_download(scale = 110,type = 'land',category = 'physical',returnclass = "sf")`
